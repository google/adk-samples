# `docs/`

`adk-samples` is a curated collection of runnable ADK agent examples.
A **recipe** is one such example — a focused, self-contained agent
that lives under `contrib/` and demonstrates one concrete ADK pattern.

A good recipe has a clear purpose, solves a concrete problem for the
ADK community, and offers something new. Please make sure the intent
and value of your recipe can be clearly stated.

## Start here

- **[`recipe-checklist.md`](./recipe-checklist.md)** — the
  one-page checklist. Everything you need to submit a recipe.
- **[`recipe-handbook/`](./recipe-handbook/README.md)** — deep
  detail. Read once when you're new; return when a checklist
  item needs more explanation.

## For contributors

Go straight to [`recipe-checklist.md`](./recipe-checklist.md).
It links out to handbook pages when you need more detail.
